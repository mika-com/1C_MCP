# /print-form — печатная форма: сначала макет, потом код

> **OpenCode:** `{SKILL_DIR}` в командах — каталог текущего навыка. Команды запускай из корня проекта. Если
> `powershell.exe` нет (Linux/macOS), запускай одноимённый `.py` соседних навыков с теми же параметрами.

Правило: **внешний вид живёт в макете, код только заполняет его.** Таблица, рамки, шрифты, ширины колонок,
объединения и подписи задаются в макете (`Template.xml`), а модуль печати берёт именованные области, подставляет
параметры и выводит их. Программное построение (`ТабДок.Область("R1C1").Текст = ...`, `.Шрифт`, `.Обвести(...)`,
`.ШиринаКолонки`) — запрещено: такую форму нельзя увидеть, проверить и поправить без отладки.

## 1. Уточни (одним вызовом `question`)

- объект и где форма живёт: документ конфигурации (`config`), внешняя печатная форма БСП (`epf`), команда печати
  БСП в расширении/конфигурации (`bsp`);
- образец (скан, PDF, картинка, существующий макет) — если есть, попроси путь к файлу и посмотри его;
- реквизиты шапки, табличная часть и колонки, итоги (сумма, НДС, прописью), подписи, ориентация (A4 книжная/альбомная);
- имя макета (`ПФ_MXL_<Имя>` для БСП) и представление команды печати.

## 2. Макет

1. Создай пустой макет: навык `template-add` — `-ObjectName <Объект> -TemplateName <ИмяМакета> -TemplateType SpreadsheetDocument [-SrcDir ...]`.
2. Опиши макет JSON DSL (`docs/mxl-dsl-spec.md`, навык `mxl-compile`). Образец — `{SKILL_DIR}/examples/invoice.json`
   (счёт на оплату). Правила:
   - области-строки с именами **`Заголовок`, `Шапка`, `ШапкаТаблицы`, `Строка`, `Итого`, `Подвал`, `Подписи`** —
     ровно те, что код будет получать через `ПолучитьОбласть`;
   - значения — параметры (`"param"`), фразы с подстановкой — шаблоны (`"template": "Счёт № [Номер] от [Дата]"`),
     постоянный текст — `"text"`; имена параметров = имена полей запроса/структуры в коде;
   - сетка мелкая и равномерная (`"page": "A4-portrait"`, 30–40 колонок `"1x"`), колонки таблицы — через `span`;
   - числа — стиль с `format` (`ЧЦ=15; ЧДЦ=2`) и выравниванием вправо; рамки — стилями `border`, а не в коде;
   - расшифровка строки — `"detail": "Ссылка..."`.
3. Собери: `mxl-compile -JsonPath <макет>.json -OutputPath <Объект>/Templates/<ИмяМакета>/Ext/Template.xml`.
4. Проверь: `mxl-validate -TemplatePath <...>/Templates/<ИмяМакета>` и `mxl-info` (области и параметры совпадают с планом).
5. **Посмотри на результат** и исправляй JSON, пока вид не совпадёт с образцом:

   ```bash
   python3 "{SKILL_DIR}/scripts/mxl-render.py" "<...>/Templates/<ИмяМакета>/Ext/Template.xml" \
     -o build/reports/print/<ИмяМакета>.html --png build/reports/print/<ИмяМакета>.png
   ```

   Открой PNG (инструмент чтения файлов показывает картинку). Слева полоса имён областей и номера строк, параметры
   показаны синим как `‹Имя›`, шаблоны — `[Имя]`. Проверь: ширины колонок (параметр обрезан — колонка узка),
   рамки таблицы сплошные, шапка не разъехалась, итоги под суммой, подписи на месте. Нужен Playwright с Chromium:
   `npm install --prefix "$HOME/.config/opencode" playwright@^1.50.0 && npx --prefix "$HOME/.config/opencode"
   playwright install chromium` (тот же, что у `web-test`); без него остаётся HTML — его тоже можно открыть.
   Рисунки поверх сетки (логотип, печать) в предпросмотр не попадают.

**Существующий макет:** `mxl-decompile -TemplatePath <...>/Ext/Template.xml -OutputPath <макет>.json` → правка JSON →
`mxl-compile` → `mxl-validate` → PNG. XML макета вручную не правь; отметь в итоге, что diff широкий (полная перегенерация).

## 3. Модуль заполнения

Эталон — `{SKILL_DIR}/examples/fill-module.bsl` (функция `ПечатьСчета`). Обязательные элементы:

- `ПолучитьМакет("<ИмяМакета>")` (во внешней обработке) или `УправлениеПечатью.МакетПечатнойФормы(
  "Документ.<Имя>.ПФ_MXL_<Имя>")` (БСП в конфигурации); области получай один раз до цикла;
- данные — одним запросом по всем объектам (`МассивОбъектов`), без обращения к реквизитам через точку в цикле;
- `Область.Параметры.Заполнить(Выборка)` + точечные `Область.Параметры.<Имя> = ...` для вычисляемых;
- между документами — `ВывестиГоризонтальныйРазделительСтраниц()`; для каждого документа запоминай
  `НомерСтрокиНачало` и вызывай `УправлениеПечатью.ЗадатьОбластьПечатиДокумента(...)` (БСП);
- разрыв страницы внутри таблицы: перед выводом строки `ТабДок.ПроверитьВывод(МассивОбластей)`; если не помещается —
  разделитель страниц и снова `ШапкаТаблицы` (повтор шапки на каждой странице); для последней строки проверяй её
  вместе с `Итого` и `Подписи`, чтобы подвал не остался один на странице;
- итоги считай в коде, сумму прописью — `ЧислоПрописью(Сумма, "L=ru_RU; ДП=Истина", "рубль, рубля, рублей, м, копейка, копейки, копеек, ж, 2")`
  (в БСП есть `РаботаСКурсамиВалют.СформироватьСуммуПрописью(Сумма, Валюта)`);
- `ТабДок.КлючПараметровПечати = "ПАРАМЕТРЫ_ПЕЧАТИ_<Объект>_<Имя>"`, ориентацию и поля задай в макете или
  `ТабДок.ОриентацияСтраницы`, `ТабДок.АвтоМасштаб = Истина`.

### Варианты подключения

| Где | Как подключить | Образец |
|---|---|---|
| Внешняя печатная форма БСП (`epf`) | `epf-init` → `epf-bsp-init` (вид `ПечатнаяФорма`) → `epf-bsp-add-command` (`Модификатор = "ПечатьMXL"`); в `Печать(...)` — `УправлениеПечатью.СведенияОПечатнойФорме` → `ТабличныйДокумент = ПечатьСчета(...)` | `examples/fill-module.bsl`, раздел «Внешняя печатная форма» |
| Документ конфигурации с БСП (`bsp`) | Модуль менеджера: `ДобавитьКомандыПечати(КомандыПечати)` и `Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода)`, макет `ПФ_MXL_<Имя>`, `СинонимМакета`, `ПолныйПутьКМакету` | `examples/manager-module-bsp.bsl` |
| Документ без БСП (`config`) | Макет у документа, команда (`CommandModule`) вызывает экспортную функцию менеджера `ПечатьСчета(Ссылка)`, результат показывается `ТабДок.Показать()` | `examples/manager-module-bsp.bsl`, раздел «Без БСП» |

Объекты на поддержке — через расширение: заимствуй документ (`cfe-borrow`), макет добавь в расширение, команду печати
— перехватом `ДобавитьКомандыПечати` (`cfe-patch-method`).

## 4. Проверка

1. `bsl-check` по модулю, `mxl-validate` по макету, `*-validate` по объекту.
2. После загрузки в базу (`db-load-*`, `epf-build`) — открой форму печати в веб-клиенте навыком `web-test`
   (кнопка «Печать») и сохрани скриншот в `build/reports/web/`.
3. В итоге назови: путь к макету, PNG-предпросмотр, модуль и команду печати.
