# Быстрый старт: goose (с окном) + навыки 1С

Пошаговая инструкция для тех, кто раньше не работал с AI-агентами. Всё делается в обычном окне
программы **goose Desktop** на Windows — командную строку открывать не нужно.

**Что получится:** вы выбираете папку своего 1С-проекта и пишете задачу обычными словами:
«добавь в справочник Номенклатура реквизит Вес», «собери обработку», «открой в браузере список
заказов». goose сам выполняет её с помощью навыков 1С.

**Из чего это состоит:**
- **goose Desktop** — программа-агент с окном чата. Она выполняет действия на вашем компьютере:
  запускает команды, правит файлы.
- **Модель (LLM)** — «мозг» агента, работает в облаке через интернет. Нужен аккаунт у поставщика
  моделей (обычно платный).
- **Навыки 1С** — 81 готовая инструкция со скриптами для работы с выгрузками 1С, базами
  и веб-клиентом.

---

## Шаг 1. Установите вспомогательные программы

| Программа | Зачем | Где взять |
|-----------|-------|-----------|
| **Git for Windows** | Обязательна. goose через неё выполняет команды навыков (Git Bash) | https://git-scm.com/download/win — при установке везде жмите «Next» |
| **Node.js** (LTS) | Для работы через браузер и защиты типовых конфигураций | https://nodejs.org — большая зелёная кнопка «LTS» |
| **1С:Предприятие 8.3** | Для сборки обработок и работы с базами. Если вы только правите XML-выгрузки — можно без неё | у вас уже есть |

## Шаг 2. Установите goose Desktop

1. Скачайте архив:
   https://github.com/aaif-goose/goose/releases/download/stable/Goose-win32-x64.zip
2. Распакуйте его в удобную папку, например `C:\Programs\goose`.
3. Запустите **Goose.exe**. Для удобства закрепите значок на панели задач: правой кнопкой →
   «Закрепить на панели задач».

## Шаг 3. Подключите модель и включите русский язык

1. При первом запуске откроется экран **«Добро пожаловать в goose»** с выбором поставщика модели.
   - Самый простой вариант — **OpenRouter**: войдите или зарегистрируйтесь в браузере, пополните
     баланс, и goose настроится сам.
   - Если у вас уже есть ключ (Anthropic, OpenAI, Google и т.п.), выберите этого поставщика
     и вставьте ключ.
2. **Какую модель выбрать.** Навыки 1С большие, им нужна сильная модель, которая хорошо работает
   с инструментами: старшие модели Claude, GPT, Gemini. Маленькие, бесплатные и локальные модели
   справляются плохо.
3. Язык интерфейса: **Settings → App → Language → Русский**. После переключения:
   **Настройки → Приложение → Язык**.

## Шаг 4. Установите навыки 1С

1. Откройте https://github.com/mika-com/1C_MCP_GOOSE, нажмите зелёную кнопку **Code** →
   **Download ZIP**.
2. Распакуйте архив в любую папку, например в «Загрузки».
3. Откройте распакованную папку и **дважды щёлкните `install-windows.cmd`**.
4. В окне должны появиться зелёные строки `[1/4]` … `[4/4]` и надпись «Готово». Нажмите любую клавишу.

Что сделал установщик:
- скопировал навыки в `C:\Users\<ваше имя>\.agents\plugins\1c` — оттуда их берёт goose;
- настроил goose на выполнение команд через Git Bash (без этого навыки на Windows не работают);
- увеличил время на одну команду до часа — обновление базы и выгрузка бывают долгими.

Если строки красные или жёлтые, прочитайте их. Обычно не хватает Git или Node.js: установите их
(шаг 1) и запустите `install-windows.cmd` ещё раз. Скачанную папку после установки можно удалить.

5. **Полностью закройте goose** и запустите снова. Если значок goose остался в области уведомлений
   у часов — правой кнопкой по нему → выход. Иначе goose не увидит новые настройки.
6. Проверка: в меню слева откройте **«Навыки»**. Там должны быть навыки 1С: `epf-init`,
   `meta-info`, `form-edit` и другие (всего 81).

## Шаг 5. Откройте папку проекта

goose работает в одной папке — **корневой папке вашего 1С-проекта**, где лежит XML-выгрузка
конфигурации или обработок (например, `C:\Projects\MyApp` с подпапкой `src`).

1. Нажмите **«Новый чат»**.
2. Внизу окна нажмите на название текущей папки → **«Выбрать каталог…»** → выберите папку проекта.

Название папки внизу окна должно смениться на ваш проект. Для следующих чатов её можно выбрать
из **«Недавних каталогов»**.

**Рекомендуется:** скопируйте файл `.goosehints` из `C:\Users\<ваше имя>\.agents\plugins\1c\goose\`
в корень папки проекта. В нём короткие правила для goose: как работать с 1С-проектом и чего не делать.

## Шаг 6. Выберите режим подтверждений

**Настройки → Чат → Режим:**

| Режим | Что делает |
|-------|-----------|
| **Умный** | Спрашивает разрешение только на рискованные действия — **рекомендуется** |
| **Вручную** | Спрашивает перед каждым действием — для осторожных, но подтверждать придётся часто |
| **Автономный** | Ничего не спрашивает — только если проект под Git и всё можно откатить |
| Только чат | Без действий — навыки работать не будут |

## Шаг 7. Работайте

Пишите задачи в поле чата обычными словами:

- «Покажи структуру справочника Номенклатура»
- «Добавь в справочник Номенклатура реквизит Вес, тип Число(15,3)»
- «Создай внешнюю обработку ЗагрузкаЦен с формой и кнопкой Загрузить»
- «Проверь все роли на ошибки»
- «Сделай расширение и перехвати в нём процедуру ПередЗаписью документа РеализацияТоваров»

goose сам выберет навык, выполнит действия и расскажет о результате. Под сообщениями видно,
какие команды он запускал. Навык можно вызвать и явно, через косую черту: `/epf-init ЗагрузкаЦен`.

Каждая новая задача — лучше в **новом чате**: так goose не путается в старом контексте и тратит
меньше денег. Прошлые чаты лежат в **«Истории сеансов»**.

> **Совет:** держите проект под Git. Если goose сделает что-то не то, изменения легко откатить.

## Шаг 8. Подключите базу 1С (если нужна)

Для сборки обработок, загрузки конфигурации в базу и обновления нужны платформа и информационная
база. Напишите goose:

> «Зарегистрируй базу: файловая, путь C:\Bases\MyApp_Dev, платформа C:\Program Files\1cv8\8.3.24.1691\bin,
> выгрузка конфигурации в папке src\cf»

goose создаст в папке проекта файл `.v8-project.json` с этими настройками
([пример](../.v8-project.example.json), [подробно](v8-project-guide.md)). После этого можно просить:

- «Загрузи изменения из src\cf в базу и обнови конфигурацию»
- «Выгрузи конфигурацию базы в XML»
- «Собери обработку ЗагрузкаЦен в epf»

Если базы ещё нет: «Создай новую файловую базу в C:\Bases\Test».

> В `.v8-project.json` могут лежать пароли. Если проект в Git, добавьте строку `.v8-project.json`
> в файл `.gitignore`.

## Шаг 9. Работа через браузер (необязательно)

goose умеет открывать базу в веб-клиенте 1С и работать в нём: нажимать кнопки, заполнять формы,
проверять отчёты, записывать видеоинструкции.

1. Нужна **опубликованная база**:
   - если база уже опубликована на веб-сервере — сообщите goose адрес: «у базы dev адрес
     http://server/dev»;
   - если нет — «Опубликуй базу dev через Apache». goose скачает Apache в папку `tools` проекта
     и опубликует базу. Нужна платформа с компонентом веб-расширения.
2. В первый раз goose сам установит браузер для автоматизации — это займёт пару минут.
3. Просите: «Открой в браузере список заказов клиентов и создай заказ для контрагента Альфа»,
   «Проверь, что отчёт Продажи за май формируется без ошибок».

## Обновление

- **Навыки 1С:** снова скачайте ZIP (шаг 4) и запустите `install-windows.cmd`, затем перезапустите goose.
- **goose:** **Настройки → Приложение → Обновления**.

## Если что-то не работает

| Проблема | Что сделать |
|----------|-------------|
| В «Навыках» нет навыков 1С | Запустите `install-windows.cmd` ещё раз и полностью перезапустите goose (шаг 4, пункт 5) |
| Команды падают с ошибками вроде `'RUN' is not recognized`, непонятные ошибки про `<<` или `&` | goose не видит настройку Git Bash. Полностью закройте goose (и в области уведомлений) и запустите снова. Не помогло — перезагрузите компьютер |
| Установщик пишет «Git Bash не найден» | Установите Git for Windows (шаг 1) и запустите установщик ещё раз |
| Команда обрывается примерно через 5 минут | То же, что выше: перезапустите goose или компьютер, чтобы применилась настройка времени |
| goose правит XML вручную вместо навыка | Скопируйте `.goosehints` в проект (шаг 5) или напишите прямо: «используй навык meta-edit» |
| «Редактирование отклонено: объект на поддержке» | Это защита типовой конфигурации. Попросите сделать доработку в расширении. Если правка точно нужна — «разреши редактирование объекта через support-edit» |
| Кракозябры вместо русских букв в ответе команды | Попросите goose сохранять вывод в файл и читать его (это правило есть в `.goosehints`) |
| `Cannot find package 'playwright'` | Напишите goose: «установи зависимости web-test» |
| goose не видит файлы проекта | Проверьте папку внизу окна (шаг 5) |

## Дополнительно: goose в командной строке (CLI)

Если удобнее терминал, то же самое делается в **Git Bash**:

```bash
curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash
goose configure                                           # подключить модель
goose plugin install https://github.com/mika-com/1C_MCP_GOOSE
cd /c/Projects/MyApp && goose session                     # работать в папке проекта
```

Настройки из шага 4 (Git Bash и время на команду) нужны и для CLI: запустите `install-windows.cmd`
или задайте переменные вручную:
`setx GOOSE_SHELL "C:\Program Files\Git\bin\bash.exe"` и `setx GOOSE_DEFAULT_EXTENSION_TIMEOUT 3600`.

`install-windows.cmd` и `goose plugin install` кладут навыки в одну и ту же папку
`.agents\plugins\1c`, поэтому нужен только один из них. Если папка уже есть, `goose plugin install`
откажется ставить повторно: обновляйте тем же способом, которым ставили.

На **Linux/macOS** Git Bash не нужен. Установите Python 3 и зависимости
(`pip install -r ~/.agents/plugins/1c/requirements.txt`): без PowerShell goose запускает
Python-версии скриптов.
